# Changelog

## 0.1.1 — 2026-10-06

- Revalidated the Duo API probe with Xcode 27.1 RC (27A9275), confirmed compatible Duo simulator inventory, and refreshed submission evidence for the current toolchain.
- Added checks for scroll position between onboarding steps, reachable actions in short folded panes, and scene orientation during display handoffs.
- Updated the pinned installation reference to this release. The capability checker remains version-independent; no checker API or installation format changed.

## 0.1.0 — 2026-10-02

- Initial skill and plugin package for auditing and adapting iOS apps for iPhone Duo.
- Capability-based Xcode discovery and SDK compile probe, with separate simulator inventory.
- Portable migration reference, project brief, and verification templates.
- Unit tests for toolchain selection and failure reporting.

This release is distributed through GitHub. It has not been submitted to the public OpenAI plugin directory.
